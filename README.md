# 미션 - 로또

## 구현할 기능 목록
### InputView
- [X] 입력을 받기 위한 Console.readLine(); 구현
- [X] 사용자가 잘못된 값을 입력할 경우 
  1. IllegalArgumentException를 발생
  2. "[ERROR]"로 시작하는 에러 메시지를 출력
  3. 그 부분부터 입력을 다시 받기

### OutputView
- [ ] 출력을 위한 템플릿 구성
- [ ] 출력 템플릿을 상수로 맞춰서 구현

### Lotto
- [ ] 로또 번호가 1과 45 사이인지 체크하는 로직 구현

### WinningNumber
- [ ] 당첨 번호를 저장하기 위한 domain
- [ ] 각 번호가 당첨 번호 안에 있는지 체크하기 위한 로직 구현
- [ ] 입력받은 당첨 번호가 1~45 사이의 로또 로직에 맞는지 체크하기 위한 로직 구현
- [ ] 입력받은 당첨 번호가 숫자가 맞느지 체크하기 위한 로직 구현

### InputParser
- [X] 입력받은 당첨 번호가 , 로 잘 나눠져 있는지 체크하기 위한 로직 구현

### BonusNumber
- [X] 보너스 번호를 저장하는 로직
- [X] 1~45 사이의 숫자가 맞는지 확인 필요

### YieldCalculatorService
- [ ] 수익률 계산하기 위한 기능
- [ ] 얻은 수익 / 구매 금액 * 100으로 수익률을 계산해서 저장한다.
